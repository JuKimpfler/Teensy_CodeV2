# XM125 – 60-GHz-Radar (Acconeer A121, I²C)

Treiber für das **Acconeer XM125**-Modul. Zwei Applikationen, je nach
geflashter Firmware: **Distance Detector** (Entfernungen zu bis zu 10 Objekten)
und **Presence Detector** (Anwesenheit über schnelle/langsame Bewegung).

Dateien: `XM125.h/.cpp` (Basis, I²C-Protokoll) · `XM125Distance.h/.cpp` ·
`XM125Presence.h/.cpp`

> **Die ausführliche Dokumentation liegt in [doc/](doc/README.md)** — 12 Kapitel
> von Protokoll und Konfiguration über Kalibrierung bis Troubleshooting.

---

## Kurzeinstieg

```cpp
#include <Wire.h>
#include "XM125Distance.h"

XM125Distance radar(0x51);          // Adresse; WAKE_UP/INT unverkabelt

void setup() {
  Wire.begin();
  Wire.setClock(100000);            // mehr Toleranz für Clock-Stretching
  radar.begin(Wire);

  radar.config.startMm        = 200;
  radar.config.endMm          = 2700;
  radar.config.peakSorting    = XM125D_SORT_CLOSEST;
  radar.config.reflectorShape = XM125D_REFLECTOR_PLANAR;
  radar.applyConfigAndCalibrate();  // dauert bis ~2 s, Umgebung frei halten
}

void loop() {
  if (radar.measure(3000)) {
    for (uint8_t i = 0; i < radar.getNumDistances(); i++) {
      Serial.println(radar.getPeakDistanceRaw(i));   // ⚠ noch keine mm!
    }
  }
}
```

`Wire.begin()` muss **vor** `begin()` erfolgen — die Library ruft es nicht auf.

## Zwei Dinge, die man vorher wissen sollte

1. **Kalibrierung ist Pflicht und flüchtig.** Nach jedem Power-On einmal
   `applyConfigAndCalibrate()` — währenddessen darf sich vor dem Sensor nichts
   bewegen, weil die Umgebung als Referenz aufgenommen wird. Details:
   [07, Teil A](doc/07-Kalibrierung.md#teil-a--modul-interne-kalibrierung).
2. **`getPeakDistanceMm()` liefert noch keine Millimeter.** Die Firmware auf
   diesen Modulen kodiert die Peak-Distanz abweichend; der Umrechnungsfaktor
   ist offen. Für Messreihen `getPeakDistanceReg()` (volles Registerwort)
   protokollieren, Werkzeug: `test/XM125_WallCalibration.cpp`. Details:
   [07, Teil B](doc/07-Kalibrierung.md#teil-b--kalibrierung-der-peak-rohwerte-counts--mm).
